# Notebooks

This directory contains the Jupyter notebooks used to perform the seismic data analysis.

## Analysis Workflow

The notebooks document the main stages of the project, including:

* Data cleaning and exploratory analysis
* Feature preparation
* Principal Component Analysis (PCA)
* Unsupervised clustering
* K-Means clustering
* DBSCAN clustering
* Visualization and interpretation of clustering results

The notebooks provide the primary computational record of the analysis conducted for this project.
