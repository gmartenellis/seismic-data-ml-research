# Notebooks

This directory contains the Jupyter notebooks used to perform the seismic data analysis and machine learning workflow.

## Analysis Workflow

The notebooks document the primary computational stages of the project:

1. **Data Cleaning and Exploratory Analysis**

   * Data inspection and validation
   * Missing-value and duplicate assessment
   * Feature selection
   * Exploratory analysis of seismic variables

2. **Machine Learning Modeling**

   * Feature standardization
   * Principal Component Analysis (PCA)
   * K-Means clustering
   * DBSCAN clustering
   * Cluster evaluation
   * Visualization and interpretation of results

The notebooks provide the primary computational record of the analysis conducted for this project and demonstrate the progression from data preparation through unsupervised machine learning.
